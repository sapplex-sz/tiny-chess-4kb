A 4 KB pure-Python chess engine that talks to the make.fun env HTTP API. Fixed-node alpha-beta search with quiescence and a transposition table; no clock, no external libraries.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
